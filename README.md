# GladiatorBattle
# Практическая работа по МДК02

В репе есть схема draw.io, в которой расписано как программа работает


Консольное приложение на C#, моделирующее пошаговый бой двух гладиаторов

## Как работает

1. Пользователь вводит данные первого гладиатора:
   - Имя
   - Здоровье
   - Прочность брони
   - Защиту в процентах

2. Затем вводит данные второго гладиатора по тем же параметрам

3. Программа проверяет ввод:
   - Здоровье должно быть больше `0`
   - Прочность брони должна быть больше `0`
   - Защита должна быть от `0` до `100%`

   При ошибке программа просит повторить ввод соответствующего параметра

4. Бой идёт раундами, пока здоровье обоих гладиаторов больше `0`

5. В каждом раунде оба гладиатора наносят случайный удар от `10` до `100`.
   Счётчик всех ударов увеличивается на `2`

6. Урон рассчитывается по состоянию брони на начало раунда:
   - Если броня есть и удар больше прочности брони:
     `Урон = броня - броня * защита / 100 + (удар - броня)`
   - Если броня есть и удар не больше прочности брони:  
     `Урон = удар - удар * защита / 100`
   - Если брони нет:  
     `Урон = удар`

7. Аналогично рассчитывается урон по второму и первому гладиатору

8. Здоровье уменьшается на полученный урон

9. После этого прочность брони уменьшается на полный нанесённый удар:
   - Если прочность стала `<= 0`, броня ломается и считается равной `0`
   - Иначе выводится сообщение, что броня выдержала

10. После раунда выводятся:
    - Урон по каждому гладиатору
    - Текущее здоровье
    - Текущая прочность брони

    Здоровье не показывается меньше `0`

11. После завершения боя определяется результат
    - Если здоровье обоих `<= 0` — ничья
    - Если здоровье первого `<= 0` — победил второй
    - Иначе — победил первый

12. В конце выводится общее количество ударов за бой
